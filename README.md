# AI Travel Agency Chatbot

An n8n AI chatbot for travel and study-abroad consultancy agencies.

## Features

- AI receptionist
- Country & university information
- Lead qualification
- Conversation memory
- Human handoff
- Appointment scheduling
- Google Sheets integration
- Staff notifications
- Bangla / Banglish / English support

## Installation

1. Download `ai-travel-agency.json`
2. Open n8n
3. Go to Workflows
4. Import the JSON
5. Connect your own credentials
6. Configure Google Sheets
7. Configure the agency email
8. Activate the workflow
